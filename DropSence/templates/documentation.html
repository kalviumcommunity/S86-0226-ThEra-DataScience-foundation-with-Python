Getting Started

DropSence is a Flask-based analytics platform that helps NGOs understand and combat student dropout patterns. Follow these steps to get up and running:

  • Install dependencies: pip install -r requirements.txt
  • Run the server: python app.py
  • Open in browser: Navigate to http://127.0.0.1:5000
  • Upload data or use the default system dataset to begin analysis.

Uploading Data

The platform accepts CSV files containing student demographic and academic records. Our intelligent column mapper auto-detects your headers — you don't need exact matches.

Recognized Column Variations

Required Field Also Recognized As Auto-Generated?
Dropout Status, Left, Discontinued, Target, Outcome Must provide
Age StudentAge, Years, EnrollmentAge Random 15–20
Gender Sex, M/F, GenderIdentity Random M/F
Attendance AttendanceRate, Present, Regularity Normal ~82%
Score Marks, Grade, TestScore, GPA, Points Normal ~70
StudentID SID, ID, RollNumber, UniqueID Sequential
Region Area, Location, Zone, District, City "General"
School Institution, College, Course, Department "Unknown School"
Year AcademicYear, Grade, Session Current year

Only the Dropout column is strictly required. All other columns will be auto-generated with realistic distributions if missing.

Risk Classification Logic

Students are dynamically classified based on attendance and academic performance thresholds:

Risk Level Criteria Recommended Action
High Attendance < 60% OR Score < 40 Urgent Counseling
Medium Attendance < 75% OR Score < 60 Parent Engagement
Low Normal parameters Regular Monitoring

API Reference

DropSence exposes a RESTful JSON API that allows external applications and scripts to consume dropout analytics data programmatically.

Base URL: http://127.0.0.1:5000

GET /api/stats

Returns key dropout statistics and auto-generated insights for the currently active dataset (uploaded or default).

Example Request

# Using cURL curl http://127.0.0.1:5000/api/stats # Using Python requests import requests response = requests.get("http://127.0.0.1:5000/api/stats") data = response.json() print(data)

Success Response 200 OK

{ "status": "success", "statistics": { "total_students": 200, "total_dropouts": 68, "dropout_rate": 34.0, "at_risk": 45, "re_enrolled": 10, "avg_attendance": 70.25, "avg_score": 62.83 }, "insights": [ "[Region] North has the highest dropout rate at 42.5%", "[Age] Age group 16-20 shows the highest dropout risk at 38.1%", "[Alert] Students with attendance below 60% have a 65.0% dropout rate" ] }

Response Fields

Field Type Description
status string "success" or absent on error
statistics.total_students int Total number of students in the dataset
statistics.total_dropouts int Number of students who dropped out
statistics.dropout_rate float Percentage of students who dropped out (0–100)
statistics.at_risk int Count of students classified as High Risk
statistics.re_enrolled int Estimated re-enrolled students (simulated)
statistics.avg_attendance float Mean attendance rate across all students
statistics.avg_score float Mean academic score across all students
insights list Auto-generated human-readable insight strings

Error Responses

404 — No dataset available 500 — Internal server error
// 404 Response { "error": "No dataset available. Please upload a CSV file." } // 500 Response { "error": "<error message details>" }

POST /upload

Upload a CSV file for analysis. The uploaded file will be validated, columns will be flexibly mapped, and the data will be saved for use by the dashboard and API.

Request Format

# Using cURL curl -X POST -F "file=@students.csv" http://127.0.0.1:5000/upload # Using Python import requests with open("students.csv", "rb") as f: response = requests.post( "http://127.0.0.1:5000/upload", files={"file": f} )

Parameters

Parameter Type Description
file file CSV file (max 16 MB). Content-Type: multipart/form-data

Behavior

  • On success: redirects to / (HTTP 302)
  • On validation error: re-renders the upload page with an error message
  • Accepted format: .csv only
GET /clear-data

Clears the currently uploaded dataset and reverts the platform to use the default system dataset. Redirects to the home page.

Example Request

curl http://127.0.0.1:5000/clear-data

Behavior

  • Deletes data/uploads/uploaded_data.csv if it exists
  • Redirects to / (HTTP 302)
  • Falls back gracefully if the file is locked by another process

Backend Architecture

Built on Python Flask, DropSence uses Pandas & NumPy for vectorized data processing and Matplotlib / Seaborn for server-side chart generation.

Core Components

Module Responsibility
DataAnalyzer Loads CSV, cleans data, computes statistics, generates insights, classifies risk levels
ChartGenerator Creates 5 matplotlib/seaborn charts (region, age, yearly, gender, attendance scatter)
map_columns_flexibly() Intelligent column name matching — maps user CSV headers to expected columns
prepare_default_dataset() Initializes the default analytics database on first run or generates synthetic fallback data

Tech Stack

  • Framework: Flask 3.x
  • Data Processing: Pandas, NumPy
  • Visualization: Matplotlib, Seaborn
  • Dataset Source: Education Analytics Repository (Synthetic + Historical)
  • Frontend: Jinja2 templates, vanilla CSS, Lucide icons
